## Read and write data

- [React](./react.mdx): providers and automatically injected Inertia live props.

- [Related writes](./nested-mutations.mdx): transactional parent/child operations.
- [Shared operations](./domain-mutations.mdx): helpers and preference concurrency.
- [Rows and casts](./records-and-casts.mdx): plain data, dates, enums, and result codecs.

## Run the system

- [Replication](./replication.mdx): generation, publications, cache, and authentication.
- [Configuration](./configuration.mdx): Laravel and client settings.
- [Supported constraints](./constraints.mdx): supported models, relations, and operations.

The [API reference](/docs/0.x/api) is generated by Refquill from the PHP source
and all public client entry points, including Inertia and search. It includes signatures, types, and
links to source code. Use the guides for application setup and security decisions.
