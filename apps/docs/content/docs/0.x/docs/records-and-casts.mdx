---
title: Rows, casts, and types
description: Consume plain typed rows and explicit input/result codecs.
---

Live props contain plain decoded rows: `task.title`, `task.list?.name`, and
`task.comments`. There are no model snapshot wrappers, lazy model methods, or
bound CRUD methods. Generated `TaskRow` describes model columns; generated page
types add the exact selected relationship shape.

Only resolved database columns replicate. Accessors, encrypted casts, appended
properties, and arbitrary DTO methods do not execute in JavaScript. Supported
primitive, JSON, date, and backed-enum metadata determine public values.

Date-cast fields expose `Date`. Native temporal storage uses epoch milliseconds;
supported date-cast string columns retain their declared UTC storage format.
Query/mutation arguments encode before native request construction. Raw ordering
values, not decoded dates, remain the cursor authority.

Mutation outputs are explicit JSON contracts. No-return (`void`) differs from
explicit null. Scalars, lists, and object-shaped results are validated before
authoritative commit and narrowed again by generated client codecs. A model is
not implicitly serialized, and a PHP HTTP response is not a mutation result.
Client and server results may have deliberately different contracts.

JavaScript numeric precision still applies to bigint and decimal data. Arbitrary
custom model casts and object-valued mutation property reads require an explicit
supported codec/projection; unsupported semantics fail generation.
