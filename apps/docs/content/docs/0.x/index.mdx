Zero for Laravel brings [Rocicorp Zero](https://zero.rocicorp.dev) to Laravel,
with model contracts, authentication, policies, validation, and replication controls.
Declare queries and mutations in controllers, generate coordinated PHP and native
TypeScript contracts, and receive typed live props in Inertia pages.

Laravel authenticates reads and authorizes writes. Zero owns replication, local
subscriptions, optimistic replay, and reconciliation. One resolved model contract
controls queries, mutation inputs, and the PostgreSQL publication's columns.

These docs cover **v0.5.0**, with **Zero 1.11.3**, **Laravel 12 or 13**, and
**PHP 8.3+**. This is a breaking replacement for the v0.4 API.
[Install matching packages](./docs/getting-started.mdx) or follow the
[v0.4 upgrade guide](./docs/upgrading.mdx).

## How data moves

1. Eloquent models declare visibility and column rules; controllers declare operations.
2. `zero:generate` analyzes registered actions and emits schema, row types,
   named controller modules, native queries/mutators, and matching PHP registrations.
3. `zero:sync-publication` limits replication to approved tables and columns.
4. The browser subscribes through Zero; Laravel rebuilds queries using trusted
   authentication context.
5. Mutations run optimistically on the client and pass Laravel policies and
   FormRequests before committing through Eloquent.

Browser context never establishes server authority. Keep cache credentials on
the server and configure read visibility and write policies independently.
